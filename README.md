# Landing Pages

Colecao de landing pages estaticas criadas para praticar direcao visual, responsividade e interacoes em JavaScript puro.

O repositorio junta dois estudos diferentes: uma pagina imobiliaria de alto padrao e uma pagina para loja de suplementos. Cada uma tem identidade propria, sem depender de framework ou processo de build.

## Projetos

### Aurelia Imoveis

Local: `imobiliaria/`

Landing page para imoveis de alto padrao. A pagina usa video no hero, navegacao por secoes, cards de propriedades, numeros animados e um visual mais sofisticado para passar a ideia de curadoria e exclusividade.

Pontos principais:

- Hero com video local.
- Menu desktop e mobile.
- Secoes de sobre, imoveis, equipe, duvidas e contato.
- Cards de propriedades com nomes, localizacoes e detalhes.
- Contadores animados.
- Interacoes de scroll via JavaScript.

### Loja de suplementos

Local: `loja de suplementos/`

Pagina estatica para uma loja de suplementos. O foco aqui e uma experiencia mais direta de produto: vitrine, chamada comercial e interacoes simples no navegador.

## Stack

- HTML
- CSS
- JavaScript

## Rodando

Abra uma das paginas no navegador:

```txt
imobiliaria/index.html
loja de suplementos/index.html
```

Nao precisa instalar dependencias.

## Observacoes

Sao landing pages de frontend puro. Nao existe backend, CMS, checkout real ou banco de dados neste repositorio.
